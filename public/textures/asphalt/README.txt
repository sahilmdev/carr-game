Optional real photo textures for the asphalt. Put three files here, named exactly:
  color.jpg      (also called Diffuse / Albedo / Base Color)
  normal.jpg     (the OpenGL normal map, often "nor_gl" or "NormalGL")
  roughness.jpg  (Roughness)
Missing files are ignored and the built-in procedural texture is used instead.
See REALISM-GUIDE.pdf in the project folder.
