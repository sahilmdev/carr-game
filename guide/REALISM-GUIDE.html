1Real sky photo (HDRI)

An HDRI is a 360° photo of a real sky that stores real brightness. The game uses it as the visible sky, as the source of all reflections, and to place the sun. The sun direction and color are detected automatically from the brightest spot in the photo, so the shadows will match.

Already done. The game ships with one photo per time of day. Where they go: claude-game/public/hdri/morning.hdr, midday.hdr and sunset.hdr, exactly those names, .hdr format (not .exr, not .jpg). Night is always the generated sky. Replace one only if you want a different look. Always pick a "Pure Sky" version: photos with trees, hills or pylons on the horizon show them floating behind the track.

What to pick

  • Resolution 2K (about 5–8 MB). 4K looks barely better and loads slowly; 1K is blurry.
  • Clear or partly cloudy sky with a visible sun, sun not straight overhead. Morning or afternoon gives nice long shadows.
  • "Pure sky" versions (sky only, no ground or buildings) work best, because the game has its own ground.
  • Avoid indoor, night, studio or heavily overcast HDRIs, which have no clear sun.

4A realistic car model

Already done: your Mazda RX-7 (Anokino, CC-BY, credited) is installed; its wheels and lamps are found automatically. The notes below are for swapping in another car.

Where it goes: claude-game/public/models/car_hq.glb. If that file exists, the game uses it instead of the old car; delete it to go back. The game automatically scales it to 4.5 m long, turns it to face forward and puts it on the road.

Requirements (check before downloading)

RequirementWhy
Format: .glb or .gltfThat's what the game loads. If you only get .fbx, .obj or .blend, convert it (see Step 6).
File size under ~20 MB (ideally under 10)Big files load slowly in the browser. Step 6 shows how to shrink them.
20k–150k trianglesEnough detail to look real, light enough for your laptop GPU. Sketchfab shows the triangle count on each model page.
Separate wheels, named with "wheel"Needed for the wheels to spin and steer. Front wheels should also contain "front", "FL" or "FR" in their names. Without this the car still drives; the wheels just won't turn.
PBR materials / textures includedThe game keeps a realistic model's own materials (paint, chrome, glass) instead of repainting it.
License allows useCC0 or CC-BY are best. Don't use "editorial only" models or anything with a real brand logo if you plan to publish the game.

5Realistic buildings and props

Important: the town buildings are now generated in code. Shops, apartment blocks and towers (the town_shop / store / diner / kiosk / awning / tower2, building, skyscraper and house slots below) come from src/game/Buildings.ts, so downloaded files with those names are ignored until you open src/game/Scenery.ts and change USE_PROCEDURAL_BUILDINGS = true to false. The same goes for palm.glb and town_tree.glb: they are generated by src/game/Trees.ts until you set USE_PROCEDURAL_TREES = false in the same file. Every other model in the table (lamps, signs, vans, benches, cliffs…) is used straight from the file.

The rest of the scenery uses free low-poly models in claude-game/public/models/. To upgrade one, replace the file with a new .glb of the same name. The game scales each model to the right height and places it automatically, so the new model doesn't need to match the old one's size. Rename the old file first (for example town_shop_old.glb) so you can go back.

6Converting and shrinking 3D files

A. Check a model before using it (30 seconds)

Drag the .glb onto https://gltf-viewer.donmccurdy.com/. You'll see whether it looks right and how big it is. Open the "Scene" panel to read node names (to check the car's wheels are called "wheel…").

B. Shrink a big .glb (easiest, in the browser)

  1. Open https://gltf.report/ and drop the .glb in.
  2. Open the "Script" tab and run the default optimize script (or one that uses draco() and textureCompress).
  3. Click Export and save. The game already supports Draco-compressed files.

C. Shrink with one command (if you have Node.js; you do)

npx @gltf-transform/cli optimize input.glb car_hq.glb --compress draco --texture-compress webp --texture-size 2048

Docs: https://gltf-transform.dev/. This usually cuts file size by 5–20×.

D. Convert .fbx / .obj / .blend to .glb (Blender, free)

  1. Install Blender: https://www.blender.org/download/
  2. File → New → General, select and delete the default cube (X key).
  3. File → Import → FBX / Wavefront (.obj) (for .blend files just open them).
  4. For a car: in the Outliner (top right), rename the 4 wheel objects to wheel_FL, wheel_FR, wheel_RL, wheel_RR (front-left, front-right, rear-left, rear-right).
  5. File → Export → glTF 2.0. Format: glTF Binary (.glb); under Data → Compression tick it for Draco. Export.

7Playtest and report back

I could check screenshots and frame timing in my browser, but only you can tell how it feels on your screen. Run npm run dev in claude-game and drive a full lap. The easiest way to compare quality levels is the in-game SETTINGS menu (Graphics: Auto / Low / Medium / High). The URLs below do the same thing for quick testing.

URL to openWhat it does
http://localhost:5188Normal. Uses whatever you picked in Settings; Auto = Medium on your Intel GPU.
http://localhost:5188/?hqMakes Auto pick High (ambient occlusion + 4K shadows). Only applies when Settings → Graphics is Auto.
http://localhost:5188/?lowfxMakes Auto pick Low. Only applies when Settings → Graphics is Auto.
http://localhost:5188/?skipcountdownSkip the 3-2-1 countdown (combine: ?hq&skipcountdown)

Tell me about any of these:

  • Stutter or low frame rate: where on the track, and at which Graphics setting
  • Driving feel: too much or too little body roll, bounce, smoke, skid marks or motion blur
  • Sound: engine too loud or quiet, gear shifts, tyre squeal, wind, rain
  • Night and rain: too dark or bright, puddles, rain streaks, lamp glow
  • Nitro: too strong or weak, tank too short or long, flames visible enough
  • Photo mode: camera speed, mouse look sensitivity
  • Flickering or crawling shadows or textures (especially on the road)
  • Anything still purple, neon or cartoonish that bothers you
  • Too bright, too dark, too foggy, or washed-out colors
  • The car: size, height, color, wheels
  • Problems after adding an HDRI, texture or model (also press F12 → Console and copy any red errors)

8Licenses and credits

  • CC0 (Poly Haven, ambientCG, cgbookcase, Kenney, Quaternius): no credit required.
  • CC-BY (many Sketchfab models): you must credit the author in any published version. Add a line to claude-game/public/models/CREDITS.md with the file name, the model page link, the author and "CC-BY".

Graphics quality, volume, motion blur, camera distance and time of day are now in the in-game menu. The settings below are one-line code edits; save the file and the dev server reloads instantly.
